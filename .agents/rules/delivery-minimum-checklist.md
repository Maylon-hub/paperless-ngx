A avaliação será baseada nas evidências deixadas no repositório e no vídeo final de síntese. Antes de
entregar, o grupo deve verificar se o repositório contém evidências claras para as atividades realizadas.

Checklist mínimo:
• Repositório aberto e acessível;
• Issues documentando as atividades do projeto;
• Vídeos da entrega preliminar na pasta videos;
• Testes de unidade com pytest;
• Relatório de cobertura;
• Configuração do GitHub Actions;
• Configuração do SonarQube ou SonarCloud;
• Mudanças implementadas e testadas;
• Correções de problemas apontados pela análise estática;
• Pull request submetido ao projeto original.

A entrega principal consiste no link do repositório e em um vídeo de síntese apresentando o
que foi realizado: build, execução, testes, cobertura, pipeline, SonarQube/SonarCloud, mudanças
implementadas e pull request.
